# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/5omeOtherGuy/Matterweave/security/advisories/new),
not in a public issue. You will get an acknowledgement within 7 days.

Fixes go through a private security advisory: the fix is released, the advisory is
published and the reporter is credited.

## Supported versions

Only the latest prerelease (currently the 0.5 line) receives security fixes.
