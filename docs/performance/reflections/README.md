# Reflection host evidence summaries

Generated by `cargo run -p matterweave-render --example reflection_validation`
(linear offscreen target, shipping `world.wgsl` SPIR-V, renderer group-0 layout).

- [manifest.json](manifest.json) — every acceptance case with PASS/FAIL/NOT RUN.
- [probes.txt](probes.txt) — one line per predetermined probe: hit/miss, reflected
  material, hit cell, colour error, crossing gap and hit clearance.

The raw PPM captures are larger binary evidence and stay outside Git at
`/mnt/bench/matterweave-dev/hy4-reflections/evidence/host/`, referenced by
SHA-256 in the branch report and in
[reflections-engine.md](../reflections-engine.md). Two pairs are intentionally
byte-identical and that is the evidence:

- `01-reflection-off.ppm` == `03-object-removed-off.ppm`: deleting the reflected
  object changes nothing while reflection is off, so the object is outside the
  camera frustum and only ever appears through the reflection.
- `08-scene-replaced.ppm` == `09-renderer-recreated.ppm`: recreating the device,
  renderer and pipelines reproduces the same image.
