## Useful failures and corrections

- Independent review found that requesting current surface pre-transform without
  transforming the scene/HUD would break Android landscape orientation. The
  baseline now requires supported IDENTITY and delegates rotation to compositor.
- An initial Xvfb smoke timed out because an unfocused window did not redraw.
  Explicit smoke mode now continues drawing while ordinary app focus pause remains;
  input cancellation is preserved and the behavior has a regression test.
- Corrupt-save recovery originally risked replacing the unreadable original on
  first edit. Numbered recovery sidecars now preserve original bytes and existing
  invalid sidecars, and restore the latest valid recovery on restart.
- First Gradle task discovery did not exercise aapt2 downloads, leaving two
  missing checksums for actual assembly. Their trusted Google artifacts were
  added to verification metadata, followed by a normal verification-enforced build.
- The first copied Gradle distribution checksum accidentally included a character
  from adjacent command output; wrapper verification rejected it. Corrected it
  against the official distribution checksum and rebuilt successfully.
- NDK llvm-readelf crashed while printing the full unstripped symbol table.
  GNU readelf successfully inspected the immutable library extracted from the
  APK; this tool failure is not recorded as a passed NDK inspection.
